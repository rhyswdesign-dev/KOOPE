# Cocktail Images

High-quality cocktail photography for recipe thumbnails.

## Image Mapping

Save the individual cocktail images with these filenames:

1. `espresso-martini.png` - Dark coffee cocktail in coupe glass
2. `margarita.png` - Salt rim, lime garnish in margarita glass
3. `mimosa.png` - Champagne flute with orange juice
4. `mojito.png` - Highball with mint and ice
5. `negroni.png` - Rocks glass with orange peel
6. `pina-colada.png` - Hurricane glass, creamy with pineapple
7. `aperol-spritz.png` - Wine glass with orange slice
8. `old-fashioned.png` - Rocks glass with orange peel
9. `dark-stormy.png` - Highball with lime

## Instructions

1. Save each image to this directory with the filename above
2. Run: `npx tsx scripts/update-cocktail-images.ts`
3. This will update the database to use these local images
