# Bartender Hacks Roadmap

## Goal
Turn mini decks into a collectible in-app system that feels earned, practical, and worth revisiting.

## Product Framing
- Internal format: `mini_deck`
- User-facing label: `Bartender Hack`
- Collection concept: a saved field-guide library users unlock through lesson progress

## Design Rules
1. Hacks should unlock after progress, not before a lesson starts.
2. Every hack should reinforce the exact decision or system the user just learned.
3. Free users should get the full practical core path.
4. PLUS should get cultural and presentation breadth.
5. PRO should get the deepest technical references.

## Launch Distribution
- Total hacks: `28`
- Free: `22`
- PLUS: `2`
- PRO: `4`
