# Unlock Content Framework

## Goal
Design unlockables that feel earned, premium, and shareable without turning every reward into the same thing.

## Core Product Principle
Unlocks should do three jobs at once:
1. reward progress
2. reinforce what the user just learned
3. create something worth saving or sharing

## Reward Tiers

### 1. Standard Unlock
Use for:
- early and mid-module wins
- useful practical recipes
- low-friction progression rewards

Format:
- in-app unlock only
- normal recipe detail page
- optionally export later

Best content types:
- classic specs
- simple riffs
- approachable zero-proof drinks
- starter batch recipes

Perceived value:
- useful
- light premium feel

### 2. Premium Recipe Card
Use for:
- checkpoint rewards
- first meaningful unlock in a module
- rewards that should feel collectible

Format:
- branded and lightly watermarked
- portrait recipe card
- optimized for saving/sharing
- 1 card per recipe

Best content types:
- house specs
- premium riffs
- signature zero-proof builds
- pairing-driven serves

Perceived value:
- collectible
- polished
- clearly earned

### 3. Mini Deck Unlock
Use for:
- advanced recipes
- PLUS / PRO rewards
- checkpoint rewards for more complex modules
- recipes with supporting sub-components

Format:
- 3 to 5 slide mini-deck
- shareable carousel format
- watermarked
- richer storytelling and process detail

Best content types:
- infusion-driven cocktails
- bitters recipes
- cordial builds
- clarified drinks
- batching specs
- advanced hosting builds

Perceived value:
- premium
- educational
- highly shareable

## Watermarking Rules

### Objective
Protect brand identity and increase perceived exclusivity without making the content feel defensive.

### Watermark system
Each premium card or deck should include:
- subtle `KOOPE` watermark
- module badge
- tier tag if relevant (`PLUS` or `PRO`)
- optional unlock line such as `Unlocked in KOOPE`

### Placement
- lower edge stamp
- soft background emboss
- never cover ingredient text or hero visual

### Tone
- premium and quiet
- not aggressive or intrusive

## Standard Content Templates

## Template A: Standard Unlock Recipe
Use for: normal lesson rewards

Fields:
- recipe name
- one-line hook
- ingredients/spec
- method
- garnish
- glassware
- flavor note
- lesson source

In-app only version:
- recipe image or gradient header
- clean spec list
- quick method
- one “why it works” line

## Template B: Premium Recipe Card
Use for: checkpoint recipe rewards

### Card structure
1. Hero panel
- recipe name
- hero image
- one-line hook
- watermark
- module badge

2. Spec panel
- ingredient list
- quantities
- glassware
- garnish
- batch notes if relevant

3. Technique panel
- method steps
- service tip
- one troubleshooting note

4. Flavor panel
- tasting note
- pairing note
- why this recipe was unlocked here

Recommended dimensions:
- portrait card
- social-share friendly
- easy screenshot/save format

## Template C: Mini Deck Unlock
Use for: advanced and exclusive content

### Slide 1: Hero
- drink name
- hero visual
- module badge
- reward tier
- watermark

### Slide 2: Full Spec
- ingredients
- ratios
- garnish
- glassware
- serving notes

### Slide 3: Supporting Build
One of:
- syrup recipe
- infusion recipe
- cordial recipe
- bitter recipe
- prep recipe

### Slide 4: Build Logic
- method
- why it works
- balancing note
- substitution note

### Slide 5: Use Case
- hosting note
- pairing note
- lesson connection
- share/save CTA inside app context

## Recommended Launch Inventory

### Standard Unlocks
- 10 to 12 recipes

### Premium Recipe Cards
- 8 to 10 recipes

### Mini Decks
- 8 to 10 assets

### Total reward assets
- 26 to 32 unlockables

This is enough to feel meaningful without overwhelming production.

## Production Priority

### Phase 1
Build first:
- Bartending Basics checkpoint card
- Flavor checkpoint card
- Mocktails checkpoint card
- Batching checkpoint card

### Phase 2
Build next:
- Techniques syrup mini deck
- Flavor pairing mini deck
- Batching citrus punch mini deck
- Global Tour recipe pack

### Phase 3
Build premium branch:
- Mastery premium cards and decks
- PRO-exclusive advanced assets

## Recommendation
Recipes should remain the center of the unlock system.

But the most valuable rewards should not be just recipes.
They should be recipe-led assets:
- premium cards
- mini decks
- supporting build inserts

That gives you a system that feels collectible, teachable, and worth sharing.
