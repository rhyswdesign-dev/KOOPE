## IMPORTANT: To See Images in App

After adding new images, you MUST clear the app cache:

1. **Delete the app** from your device/simulator
2. **Reinstall** by running `npx expo start` and scanning QR code
3. **Or** shake device → "Clear React Native Cache" → Reload

The cache stores old image URLs, so you need to force a fresh load.

## After Creating Images

Once images are created and placed in `assets/images/cocktails/`, add them to `assets/images/cocktails.ts`:

```typescript
export const COCKTAIL_IMAGES: Record<string, any> = {
  // Existing images...

  // Add new ones like this:
  'manhattan': require('./cocktails/manhattan.png'),
  'moscow-mule': require('./cocktails/moscow-mule.png'),
  // ... etc
};
```

Then the images will automatically appear on both recipe cards and detail pages!
